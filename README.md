# Expedição Piraíba

MVP da plataforma de reservas e operação da Expedição Piraíba.

## Stack

- Next.js, React, TypeScript e Tailwind CSS;
- Django e Django REST Framework;
- PostgreSQL;
- Docker Compose.

## Desenvolvimento local

```bash
docker compose up --build
```

- Frontend: http://localhost:3000
- API: http://localhost:8000/api/health/
- Administração: http://localhost:8000/admin/

As regras funcionais estão em `documentos/sdd/base_conhecimento_mvp_expedicao_piraiba.md`.
