# Checklist visual — telas do MVP

Este documento complementa a base funcional. Os mockups em `documentos/sdd/imgs` são a referência visual oficial; uma tela só pode ser considerada visualmente concluída quando os itens correspondentes abaixo estiverem presentes e responsivos.

## Tela 01 — Home

- [x] Cabeçalho com logo, navegação e WhatsApp.
- [x] Hero compacto com proposta principal.
- [x] Ícones de calendário e WhatsApp nos CTAs do hero.
- [x] Introdução lateral de próximas expedições com o texto “Viagens com saídas...”.
- [x] Cards com data, localização, duração, ponto de saída, preço e vagas.
- [x] Quatro diferenciais com ícones: organização, estrutura, reserva e atendimento.
- [x] Prévia de galeria com fotos reais e CTA para a galeria.
- [x] Logo e informações institucionais no rodapé.

## Tela 02 — Detalhes da Expedição

- [x] Identificação, período, duração, capacidade, preço e vagas.
- [x] Galeria/destaque visual da expedição.
- [x] Itens inclusos organizados em lista com ícones.
- [x] Estrutura e conforto organizados como recursos com ícones.
- [x] Espécies encontradas.
- [x] Seção “Como será sua expedição” com roteiro por dias.
- [x] Faixa de confiança: segurança, equipe especializada, pagamento seguro e suporte.

## Tela 03 — Checkout

- [x] Dados do comprador.
- [x] Participantes.
- [x] Modalidade: sinal ou integral.
- [x] Método: PIX ou cartão.
- [x] Termos da expedição e política de cancelamento.
- [x] Resumo financeiro e proteção temporária das vagas.
- [x] Mensagem “Pagamento 100% seguro” com ícone.
- [x] Rodapé/faixa de confiança.

## Pendências externas

- [ ] Número e URL oficiais do WhatsApp.
- [ ] URLs e textos jurídicos definitivos dos termos e da política de cancelamento.
- [ ] Fotografias aprovadas e autorização de uso registrada.
